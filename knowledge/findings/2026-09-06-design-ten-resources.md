# Design-Ten — the 10 design resources from the TG favorites list

Collected 2026-09-06 from the owner's Telegram favorites (UI/UX designer post).
All ten verified alive. Post claimed "everything is free" — annotations below
correct that where it lies.

| Resource | URL | Status | Notes |
|---|---|---|---|
| Design Library | https://curations.supply | alive | curated directory of design curations, weekly newsletter; free |
| Landing Pages | https://landing.love | alive | landing-page gallery; free |
| SaaS Websites | https://saaspo.com | alive | SaaS site screenshots/patterns; free tier, some gated content |

## Usage notes

- For UI work in this workspace, pair inspiration sources with the
  `antislop` skill family (installed 2026-09-06): direction comes from a
  DESIGN.md, not from browsing alone.
- `mobbin` and `hugeicons` freemium walls are the only deviations from the
  post's "all free" claim; everything else checks out.
- Verify-status: alive URLs confirmed via web search 2026-09-06; feature/price
  labels spot-checked, may drift.
