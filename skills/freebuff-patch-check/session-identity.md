# Session A* Identity

At the beginning of every session, including ordinary non-autonomous work, choose a short working designation in the `A*` form from the current task. The designation is session-scoped and must not be confused with an autonomous worker identity.

## Required startup record

Before substantive work, state or record:

- **Agent:** the selected designation, for example `A1` or `A2` when the task needs a distinct slot
- **Task:** the concrete user outcome being pursued
- **Mode:** production, experimental, plan, or build
- **Scope:** files, services, or external systems that may be touched
- **Verification:** the evidence that will determine completion
- **Blockers:** known uncertainty or dependency

Use `A1` when there is no active conflicting designation or when this is the normal single-agent session. Choose the next available `A*` only when another active workstream already owns the current designation. Do not invent parallel agents; the label identifies the current workstream only.

The first substantive progress note should include this identity record. If the task changes materially, update the task and verification fields while keeping the same designation unless the workstream is explicitly split.
