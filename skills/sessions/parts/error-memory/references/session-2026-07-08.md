# Session Error Patterns — 2026-07-08

## OpenSERP / Search

| Pattern | Solution |
|---------|----------|
| Bing captcha_detected after N queries | Switch to Yandex engine, add delays |
| DDG always captcha_detected | Skip DDG entirely, use Bing+Yandex |
| OpenSERP extract works when search fails | Use `/extract?url=URL` as fallback |
| `python3` command not found | Use `python` (venv), not `python3` |
| `execute_code` subprocess BLOCKED | Use `terminal` directly |

## CloakBrowser

| Pattern | Solution |
|---------|----------|
| First launch hangs 30+ min | Normal — downloading 200MB Chromium. Check `~/.cloakbrowser/`. Kill+restart if binary cached. |
| `FileNotFoundError` on write | Target directory doesn't exist. `mkdir -p` first. |
| APKPure download → login redirect | Use main page, not `/download`. Or let user download manually. |
| `download.apkpure.com` = 403 Cloudflare | Direct URL blocked. Need full browser session. |

## WSL / Kali

| Pattern | Solution |
|---------|----------|
| `wsl bash -c "..."` breaks quotes/vars | Write .sh file, then `wsl bash /mnt/c/tmp/file.sh` |
| `unzip` not found in Kali | Extract on Windows side with `unzip`, copy to WSL |
| `strings` not in git-bash | Use WSL Kali: `wsl -d kali-linux strings /mnt/c/path/file` |

## APK/XAPK

| Pattern | Solution |
|---------|----------|
| libil2cpp.so not in main APK | It's in `config.armeabi_v7a.apk` or `config.arm64_v8a.apk` |
| Original is arm64-only, mod is 32-bit | Get 32-bit original for comparison |
| XAPK = 4 split APKs | Extract ALL, libs in config.*.apk |

## Telegram / Hermes

| Pattern | Solution |
|---------|----------|
| Markdown tables crash client | Bullets only, never tables |
| web_search returns error | Use OpenSERP |
| browser_console → null | Use `browser_snapshot(full=true)` |
| `python3` = stub on Windows | Always use `python` |
| write to new dir = FileNotFoundError | `mkdir -p dir` first via terminal |
