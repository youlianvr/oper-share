# Workspace Setup: Install, Update, Migrate

Primary source: the selected project-local `SETUP.md`. For AGGG2.7, use
`projects/AGGG-3.0/docs/canon/SETUP.md` and run commands from that project root (or use
explicit project-root paths). AGGG2.0 is a self-contained project tree: canon docs,
skills, db-tools, MCP servers, databases, installers. The root is not hardcoded in
code — it is resolved by that project's `_compat.py` via `$AGGG2_ROOT` or its
project-local markers. This skill does not define the Oper root setup path.

## Workflow (order of application)

1. **What to copy, what not.** Canon docs live in the selected AGGG2.7 project root; do not copy them into Oper. Project setup may distribute AGGG2.7 skills, AGENTS mirrors, MCP configuration and `vpnctl` through its own `scripts/setup.py`; verify target paths before running it.
2. **Requirements.** python3 (mandatory), node+npm (npm harnesses), bun (omp), curl (opencode), git (updates via pull). setup.py doesn't install anything system-level — it honestly diagnoses.
3. **New hardware from scratch (even without python).** Industry pattern — mise (replaces nvm/pyenv/asdf, no sudo): `./scripts/bootstrap.sh` (Linux/macOS) or `.\scripts\bootstrap.ps1` (Windows, winget: mise → runtimes → setup.py). `--check` — plan without installation. If runtimes already exist — just runs setup.py. mise shims go at the END of PATH — system versions aren't overridden.
4. **Python already exists.** `python3 scripts/setup.py` (Linux/macOS) / `python scripts/setup.py` (Windows — no python3, only python). Flags: `--check` (plan), `--skip-mcp`, `--skip-harnesses`, `--skip-lsp`, `--skip-db`, `--skip-doctor` etc. Everything is idempotent — can be re-run.
5. **What setup.py does.** Project venv (`~/.venvs/aggg2`), MCP dependencies, Camoufox browser (~150MB, on failure a warning + `venv/bin/python -m camoufox fetch` later), distributes AGENTS.md and skills (`scripts/install/install_agents.py --all`; separately `--skills`/`--agent-skills`/AGENTS.md only), MCP servers (`scripts/install/install_mcp.py`), LSP servers (`scripts/install/install_lsp_servers.py`), harnesses (`scripts/install/install_harnesses.py`), databases (`build.py`), `vpnctl` symlink.
6. **Two dependency sets (one venv).** `mcp/requirements.txt` (MCP layer) + `projects/sherpa-voice/requirements.txt` (project). setup.py installs only the MCP set; the project installs via its `./run.sh`. Windows: `venv\Scripts\python.exe -m pip install ...`.
7. **Windows: UTF-8 for console.** Default console is cp1251 — unicode output (✓/✗/Cyrillic) crashes with UnicodeEncodeError. Scripts switch stdout themselves; for third-party utilities: `[Environment]::SetEnvironmentVariable("PYTHONUTF8", "1", "User")` + restart console (or `$env:PYTHONUTF8=1` one-time).
8. **Diagnostics after installation.** `python3 scripts/doctor/doctor.py` (mirrors, venv, MCP, agent-lsp, tests) / `--json` (CI). LSP separately: `scripts/install/install_lsp_servers.py --check/--doctor/--only-config`. Harnesses with selection: `scripts/install/install_harnesses.py --list`, `deepcode omp`, `--exclude`, `--force`.
9. **Updating.** Only inside the selected AGGG2.7 project root: update its repository/archive, run its `scripts/setup.py`, then its documented project tests. Do not run `git pull`, archive extraction, or setup against the Oper root by assumption.
10. **Building an archive for sharing.** Use the selected project's documented archive command only after verifying its root and output path. This skill review does not authorize archive creation or password handling.
11. **Health check.** `vpnctl status` (if sing-box needed), `opencode mcp list` (MCP connected), `python3 db-tools/search.py "test"` (database works), `./projects/sherpa-voice/run_tests.sh` (tests).

## Gotchas

- Disk mount point may change — file paths are examples, substitute real ones.
- `install_lsp_servers.py` on CI (`CI=true`) skips heavy downloads (clangd/lua) — this is by design.
- `scripts/install/install_agents.py` doesn't remove orphaned skills from harnesses — after removing a skill from canon, clean harnesses manually.
- Windows: winget may be missing — LSP script falls back to scoop/choco.
