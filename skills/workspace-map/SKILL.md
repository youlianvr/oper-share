## Rules firmware (how core gets into agents)

- **Source of truth — `AGENTS.md`** for repository-local policy; runtime loader behavior must be confirmed from the installed bundle and hooks.
- **Runtime:** the host/Freebuff loader supplies the effective system prompt and tool surface; this repository documents the observed contract but does not claim a separate AGGG harness.
- **Session hooks:** `.claude/hooks/` contains repository hooks; their execution is an observed integration detail, not a replacement for `AGENTS.md`.
- **Active skills:** the on-disk `skills/` set is the repository membership boundary; use `find-skills` and the format audit to load and verify them.
